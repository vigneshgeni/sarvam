# Sarvam design v3: design package, samples and final prompts

Put this folder in the repo as `design/sarvam-v3/`. **Start with `STEP_BY_STEP.md`.**

| Folder / file | What |
|---|---|
| `STEP_BY_STEP.md` | Who to send what, in which order, until the app is live (Wed–Fri). |
| `prompts/1_CURSOR_FINAL_DESIGN.md` | Cursor: build the full design v3 (fonts, colours, motion, illustrations, every screen, Save as image, multi-document result). |
| `prompts/2_ANTIGRAVITY_FINAL.md` | Antigravity: bugs, security, performance, the multi-document API, the samples, making every designed flow work, fixing Grok's defects, merging. |
| `prompts/3_GROK_FINAL_DEPLOY_TEST.md` | Grok: deploy and test in three stages (live bug-fix check, preview design test, production). |
| `design/index.html` | Gallery of all 26 screens with looping motion. Open in Chrome. |
| `design/screens/` | Each screen as a playable page with real fonts, animations and transitions between screens. |
| `design/png/` | 2x renders: the pixel target. |
| `design/motion/` | Videos of each animated screen + `00-prototype-tour-transitions.mp4`. |
| `design/sarvam-design-v3.pdf` | All 26 screens, labelled. |
| `design/tokens.css`, `design/screen-styles.css` | Every colour, radius, font, keyframe, duration and delay. |
| `design/source/` | Raw design source (`.dc.html`) and the canvas index. |
| `design/fonts/` | Self-hosted Fraunces, DM Sans and Noto Sans (Indic) used by the screens. |
| `samples/` | The six new or changed sample documents (fictional), `SAMPLE_EXPECTED_FACTS_V3.md`, and the older expected facts. |

Screens: 01–03 onboarding · 04 Home · 05 All documents · 06–09 reading A–D · 10 insurance · 11 lab report · 12 pension in Tamil · 13 prescription · 14 challan, legal notice, investment, form · 15 one upload with several documents · 16 Listen · 17 Ask · 18 Share or save · 19 Save as image · 20 Reminders · 21 Medicine reminders · 22 Password · 23 Delete · 24 Accessibility · 25 Offline · 26 how screens adapt (and which sample makes which screen).

All names, numbers and organisations in the samples and screens are fictional.
